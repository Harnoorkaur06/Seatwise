# SEATWISE

## Intelligent Examination Seating & Conflict Resolution System

SEATWISE is a constraint-based examination seating platform designed to automatically generate secure and conflict-aware seating arrangements across multiple examination rooms.

### Phase 1 Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Node.js
- Express.js
- LocalStorage
- JSON

### Core Objective

Generate examination seating plans where students belonging to the same course code are not placed in directly adjacent seats whenever a valid arrangement is possible.

Phase 2 will upgrade SEATWISE to a MERN-based architecture with React, MongoDB, JWT authentication, drag-and-drop seat overrides, live conflict detection and university-level integration.
